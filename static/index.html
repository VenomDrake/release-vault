Procedura Guidata & Manuale Completo — Release Vault

Configurazione passo-passo di Utente, GitHub API, Nexus Mods, Bot Telegram 24/7 e Comandi

☕ Supporta / Dona
Benvenuto in Release Vault!

Questa piattaforma privata monitora i tuoi progetti GitHub e le tue mod di Nexus Mods, scaricando e catalogando automaticamente ogni versione con file binari, codice sorgente, checksum SHA256 e Patch Notes in Markdown.

🔐 1. Imposta le Credenziali di Accesso Amministratore

Scegli il nome utente e la password con cui proteggere l'accesso alla tua interfaccia web privata.

🐙 2. Come configurare GitHub Personal Access Token (Consigliato)

Senza token, GitHub limita le richieste API a 60 all'ora. Inserendo un token gratuito il limite sale a 5.000 richieste/ora e puoi archiviare anche le tue repository private.

📋 Procedura passo-passo per ottenere il Token GitHub:
  1. github.com/settings/tokens → Generate new token (classic).
  2. Imposta Expiration su No expiration e spunta il permesso "repo".
  3. Clicca su Generate token e incolla qui sotto il codice che inizia con ghp_...

🎮 3. Come configurare Nexus Mods (API Key + Session Cookie)

Per scaricare automaticamente i file delle mod, lo storico versioni e i changelog da Nexus Mods (anche con un account gratuito Free!), servono 2 parametri:

🔑 A) Personal API Key:
  1. next.nexusmods.com/settings/api-keys
  2. Scorri fino in fondo alla sezione Personal API Key, copia la chiave e incollala qui sotto.
🍪 B) Cookie nexusmods_session:
  1. nexusmods.com → F12 (DevTools).
  2. Application / Storage → Cookies → copia il valore di nexusmods_session.

🤖 4. Come creare e blindare il tuo Bot Telegram Personale 24/7

Il Vault include un servizio Bot Telegram attivo 24/7 che risponde esclusivamente al tuo Telegram User ID (bloccando chiunque altro), invia notifiche con le Patch Notes e ti permette di aggiungere link GitHub o Nexus Mods direttamente dalla chat!

1️⃣ @BotFather:
  1. @BotFather → /newbot
  2. Copia il Token HTTP API (es. 123456:AAH...) e incollalo qui sotto.
2️⃣ @userinfobot (Telegram User ID):
  1. @userinfobot → Start
  2. Copia il tuo numero Id: il bot risponderà solo ed esclusivamente a te!

📖 5. Guida Completa ai Comandi e alle Funzionalità

✨ Auto-Tag & Memoria Categorie

Incollando un link GitHub o Nexus Mods, il sistema genera in automatico Categoria e Tag e ricorda le tue categorie con pulsanti rapidi.

⚡ Solo Ultima + Future vs 📚 Storico

Scegli per ogni repo se scaricare tutto lo storico passato oppure solo l'ULTIMA release e le successive future.

⏸ Pausa Globale e Pausa Singola Repo

Metti in pausa tutti i download col tasto Pausa Tutto, oppure metti in pausa una singola repository lasciando attive le altre.

🧹 Elimina Dati & 🗄 Archivi Conservati

Con Elimina Dati svuoti i file di una repo e riparti con nuove opzioni. Quando elimini una repo puoi scegliere di Conservare i file ed esplorarli anche senza repo attiva!

🤖 Comandi del Bot Telegram (/menu, /status, /sync):

Usa /menu o /start per la Dashboard interattiva, /status per lo stato dei download e del disco, /sync per controllare aggiornamenti, oppure incolla direttamente qualsiasi link GitHub o Nexus Mods in chat!
